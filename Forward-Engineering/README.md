# Forward Engineering Documents

This folder contains the documents required for User Story Generation:

## Required Files

1. **BRD Document** - Business Requirements Document
   - Filename must contain "brd" (case-insensitive)
   - Must NOT contain "technical"
   - Supported formats: .docx, .doc, .md
   - Example: `BRD.docx`, `Business_Requirements.md`

2. **Technical BRD** - Technical Business Requirements Document
   - Filename must contain both "technical" AND "brd" (case-insensitive)
   - Supported formats: .docx, .doc, .md
   - Example: `Technical BRD.docx`, `Technical_BRD.md`

## Usage

The FMB Converter application will automatically fetch these files from this folder when generating user stories.

## Next Steps

1. Upload your BRD document to this folder
2. Upload your Technical BRD document to this folder
3. Use the User Story Generation feature in the application
